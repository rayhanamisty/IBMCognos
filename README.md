# IBMCognos


# 📊 Dashboard Designed with IBM Cognos Studio

An interactive data visualization project built using **IBM Watson Studio** (Cognos Dashboards). This repository contains the project documentation, source data, exported assets, and visual insights.

---

## 📌 Project Overview
- **Objective:** To analyze and visualize key dataset trends using IBM Watson Studio (Cognos Dashboards), translating raw complex data into an executive-level interactive dashboard that delivers actionable business insights and supports data-driven decision-making.
- **Dataset:**Zomato Resturant Dataset
- **Key Deliverable:** Interactive multi-page dashboard displaying KPI metrics, regional breakdowns, and predictive indicators.
